# Support

## Where to ask questions

Ask usage questions by opening an issue in the repository. Blank issues are enabled, so you can
open a plain issue, or use the bug report or feature request template when it fits. Include the
package, version, Node.js version, OS, adapters in use, reproduction steps, expected and actual
behavior, and any logs. The repository does not have a separate discussion forum, chat channel, or
mailing list.

<https://github.com/NehanAhmed/cred/issues/new>

## Where to report bugs

Report bugs with the bug report form:

<https://github.com/NehanAhmed/cred/issues/new?template=bug_report.yml>

Include the package and version, Node.js version, operating system, the database, email, and
framework adapters in use, reproduction steps, expected versus actual behavior, and any logs.

## Where to report security vulnerabilities

Do not report vulnerabilities in a public issue. Follow SECURITY.md and use GitHub private
vulnerability reporting:

<https://github.com/NehanAhmed/cred/security/policy>

## Before you ask

- Run `pnpm turbo run build lint typecheck test` from the repository root to confirm the failure
  is not a stale checkout.
- Confirm the package version with the latest release on npm.
- Remove secrets, tokens, passwords, and personal data from anything you paste.
